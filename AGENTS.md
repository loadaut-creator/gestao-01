# Instruções deste projeto

- O usuário exige desenvolvimento em blocos sequenciais. Trabalhe somente no bloco autorizado e só avance após a frase explícita: “BLOCO APROVADO — PODE AVANÇAR”. Ajustes solicitados mantêm o projeto no bloco atual.
- Em todos os blocos, siga `docs/design-system.md`. Use Inter, os tokens globais de `app/globals.css` e os padrões de tabelas, navegação, formulários, cards, acessibilidade e responsividade ali definidos. Toda tela deve funcionar em aparelhos celulares. Preserve a identidade azul da plataforma.
- Não introduza dados reais, lógica de BI, cálculos, autenticação ou persistência antes do bloco correspondente.
